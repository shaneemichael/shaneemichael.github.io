# shaneemichael.github.io

Personal portfolio of Shane Michael Tanata Tendy — software engineer.

Live at **https://shaneemichael.github.io**

## Stack

- [Astro](https://astro.build) — static site
- [Three.js](https://threejs.org) — particle name hero
- [GSAP](https://gsap.com) + [Lenis](https://lenis.darkroom.engineering) — scroll animation and smooth scrolling
- [Motion](https://motion.dev) — spring animations
- Web Audio API — synthesized hover sound

## Develop

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
npm run preview  # serve the production build
```

Pushing to `main` builds and deploys to GitHub Pages via `.github/workflows/deploy.yml`.
